# Task Tracker Project Status

## Where I Am

The main Task Tracker MVP features are working.

## What Is Working

- Users can add a project name, task name, and due date.
- Tasks display on the page.
- Tasks save in localStorage.
- Tasks remain after refresh.
- Dates display in a readable format.
- Tasks show Overdue, Due Today, or Upcoming.
- Tasks can be marked Complete or Incomplete.
- Completed status remains after refresh.
- Tasks can be deleted with a confirmation message.
- Deleted tasks stay deleted after refresh.

## What Is Not Working Yet

- The page still needs final styling and responsive polish.
- I still need to test the app on smaller screens.

## Next Step

Style the Task Tracker and make sure the layout works well on desktop and mobile.
